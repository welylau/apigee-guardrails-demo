# Traditional -> Simplified Chinese fold table (StaticGuardrails).
# build.py compiles this into sg-rules.js (SG_ZH_FOLD). SG.normalize() folds every
# prompt with it, and build.py folds every "norm" regex rule the same way, so a
# Chinese rule / lexicon term written once (in either script) matches TC and SC.
#
# Format: whitespace-separated 2-character tokens "<Traditional><Simplified>".
# Rules (enforced by build.py):
#   - a Traditional key may map to only one Simplified value
#   - a Simplified value must never itself be a key (no chains)
# Only characters relevant to matching are listed; it is NOT a full converter.
# Japanese kanji are folded too - harmless, because rules/terms are folded identically.
# ==============================================================================
